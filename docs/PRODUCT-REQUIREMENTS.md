# WeddingVerse — Product Requirements Document (Summary)

**Platform:** WeddingVerse (SaaS / Web Application)  
**Primary Mission:** "Design once. Data everywhere." Couple enters their wedding details once (partners, dates, events, venues, story, photos), and the schema-driven engine automatically renders an interactive luxury wedding website and an animated video invitation with zero manual designer involvement.

## Key Capabilities
1. **Interactive GSAP Landing Page**: Showcasing live dual-output (Website & Animated Video), 1,000+ template catalog discovery with filters, interactive live previews, workflow step-through, and RSVP demo.
2. **Template Discovery**: Search & filter by Occasion (Wedding, Sangeet, Mehendi, Haldi, Reception, Nikah, Anand Karaj), Culture (Hindu, Punjabi, Gujarati, South Indian, Muslim, Christian, Interfaith), Style (Royal, Minimal, Floral, Palace, Dark Luxury, Pastel), Color Palette, and Format.
3. **Smart Wedding Onboarding**: 5-step intuitive wizard to input couple details, wedding schedule, multi-day dynamic events, photos, and aesthetic preferences.
4. **Schema-Driven Template Engine**: Over 1,000+ deterministic template combinations powered by layout families, section variants, color tokens, and typography systems.
5. **Interactive Wedding Website Preview**: Full-screen responsive invitation with couple hero, countdown timer, romantic love story, dynamic multi-event timeline with calendar & map links, photo gallery, RSVP form, and guest wishes.
6. **Animated Video Maker**: Real-time canvas/HTML5 animated scene preview (Intro -> Couple -> Save the Date -> Events -> Gallery -> Venue & RSVP -> Outro) with aspect ratio switching (9:16 Story/Reel, 1:1 Square, 16:9 Cinema), soundtrack selector, scene progress, and simulated MP4 export.
7. **RSVP & Guest Management**: Real-time guest RSVP submission, guest list tracking, meal preferences, dietary notes, attendance count, and CSV export.
8. **WhatsApp & Multi-Platform Sharing**: One-click WhatsApp invite text generator with dynamic personalized links, QR code generation, and direct preview links.
